# NexGen Academy - Web Programming Assignment

Welcome to the **NexGen Academy** project repository! This is a static website built with HTML, CSS, JavaScript, and XML/XSD for a Web Programming assignment. It features a modern, responsive UI design utilizing a clean grid structure and aesthetic details.

## 🚀 Live Demo
**[Click here to view the live website!](https://Ruthvik072006.github.io/wp-assignment/)**

## ✨ Features
- **Home**: Website introduction, Navigation menu, Modern custom banner.
- **Courses**: Dynamic course catalog with grid layouts, course cards, titles, instructors, prices, and ratings.
- **Course Details**: In-depth course descriptions, instructor details, curriculum, duration, and a clear enrollment CTA.
- **Authentication**: Registration and Login forms fully validated using vanilla JavaScript.
- **Contact**: Contact information and functioning inquiry form.
- **XML Data Representation**: Structured course data via XML and validated against an XSD schema. 

## 🛠️ Built With
- **HTML5**: Semantic structure, strict page requirements built to specification.
- **CSS3**: External stylesheets, Variables, Grid System, Flexbox, hover effects, and modern aesthetics.
- **JavaScript**: Fast client-side form validations and tab switching.
- **XML / XSD**: Document validation.
